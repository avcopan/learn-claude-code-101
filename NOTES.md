# Claude Code 101

## Your first prompt

`Shift + Tab` to switch between permission modes:

- `accept edits on`: Approve edits and file creation, but ask permission to run terminal commands.
- `plan mode`: Uses read-only tools to analyze your code base and do research on your suggested implementation. Also will ask you for clarification. Returns to you a detailed plan on what it will do. This works well for planning complex projects.
